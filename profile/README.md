## 👋 Welcome to Joe's DIY Lab

I make **3D printing, car, and DIY project videos**, and along the way I build free tools to make the work easier. Everything here is open source, and most projects have a video showing how to use them.

Built by Joe Pitz / **Objetek Systems**.

## 🛠️ Tools

| Project | What it does | Video |
|---|---|---|
| [**Wave Script**](https://github.com/JoeDIYLab/wave-script) | Turns solid 3D models into FullControl-style wavy and woven prints, with no slicer needed | [Watch on YouTube](https://www.youtube.com/@JoediyLab) |

### 🔜 In the works

- **Spoolman for Windows**: run the Spoolman filament inventory on Windows without Docker
- **Bambu → Spoolman adapter**: automatically track filament used on each spool from a Bambu Lab printer
- **Non-planar post-processor**: Z anti-aliasing for smoother top surfaces on Bambu and Orca-based slicers
